## A git repository — optional

With a repository, CR-Track reviews your **staged** changes automatically about
two seconds after you `git add`, and can check before you commit.

Without one, you can still right-click any file or folder and choose
**CR-Track: Review This File**.

A `.gitignore` on its own does not make a folder a repository. If the panel says
so, click **Initialise a repository here**.
